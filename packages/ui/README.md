# Research UI

Frontend dashboard for Research Insight platform.

## Overview

Web interface for:
- Uploading research papers
- Monitoring job progress
- Generating LinkedIn content
- Viewing generated posts
- Queue health dashboard

Built with Next.js 15 and React 19.

## Getting Started

### Prerequisites

- Node.js 18+
- pnpm
- Research API running

### Installation

```bash
pnpm install
```

### Development

```bash
pnpm dev
```

Application will start on `http://localhost:3200`

### Build

```bash
pnpm build
```
